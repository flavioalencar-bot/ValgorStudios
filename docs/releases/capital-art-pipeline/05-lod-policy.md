# 05 — Política de LOD

| Nível | Uso |
|-------|-----|
| LOD0 High | close-up / High quality |
| LOD1 Medium | **padrão do produto** |
| LOD2 Low | overview / Low quality |
| LOD3 | billboard/proxy distante (opcional) |

Resolver usa `CityAmbientQuality` para escolher High/Medium/Low prefab no catálogo.
