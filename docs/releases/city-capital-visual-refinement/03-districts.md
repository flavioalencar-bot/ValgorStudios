# 03 — Distritos

| Distrito | Identidade | Edifícios |
|----------|------------|-----------|
| Royal | pedra clara, jardins, banners | Castelo, Salão dos Heróis |
| Dragon | pedra escura, landing pad, braseiros | Torre dos Dragões |
| Military | pátio, alvos, mesa estratégica | Arena, Campo, Academia |
| Economic | barracas, caixas, jardim Residência | Mercado, Residência, Armazém |
| Industrial | fornalha Fundição, toras, minério | Fundição, Serraria, Mina, Pedreira |
| Sacred | jardins, água, bancos | Hospital, Templo |
| Rural | plantações, cercas, fardos | Fazenda |

Residência ≠ casas decorativas (`CottageA/B`).  
Fundição ≠ prop industrial genérico (fornalha + chaminé próprias).  
Campo ≠ Arena ≠ Academia.
