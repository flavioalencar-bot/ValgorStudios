# Jornada do Jogador — Valgor Beta 0.1

Fluxo jogável: Splash/Loading → Menu → Novo Jogo → Criação → Intro → Cidade → Heróis/Dragões/Mapa → Salvar/Continuar.

## Fluxo

1. **Splash/Loading** — logo VALGOR, brasão, Beta 0.1, barra e mensagens (≤3s de brand)
2. **Menu Principal** — Novo Jogo · Continuar · Configurações · Créditos · Sair
3. **Criação do jogador** — nome 3–20 caracteres, perfil local salvo
4. **Intro** — 3 cards de lore
5. **Cidade** — recursos iniciais, produção, tutorial
6. **Heróis / Dragões / Mapa** — jornada guiada existente
7. **Salvar / Continuar** — PlayerPrefs + Continuar no menu

## Recursos iniciais

- Nível (Castelo): 1
- Ouro 5000 · Comida 3000 · Madeira 3000 · Pedra 2000 · Ferro 1000
- Essência de Dragão 100 · Energia 100/100

## Abrir

Build Windows: `builds/windows/Valgor-Checkpoint/Valgor.exe`
